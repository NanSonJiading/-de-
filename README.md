# 启迪de迪内容选题库智能工作流系统

这是一个本地可用的静态网页工具，用来把关键词、案例、访谈片段、茶叙记录或品牌素材转化为完整的选题库工作流结果。

## 使用方式

直接打开 `index.html`，输入素材后点击「生成工作流结果」。

系统会输出：

- 素材初步判断
- 一级、二级、三级选题匹配
- 匹配置信度
- 是否需要新增分类
- 候选分类池
- 五类标题优化
- 具体场景设计
- 五维探索拆解
- 内容结构建议
- 栏目与产品承接
- 追问问题
- 分类库更新 JSON

## 数据存储

素材记录和候选池会保存在浏览器本地存储中。可以在「素材记录」和「候选池」页面导出 JSON。

## 设计原则

系统默认优先匹配现有九个一级方向，不轻易新增分类。所有新增三级选题、候选二级方向会进入 `pending_review`，用于后续人工复核。
